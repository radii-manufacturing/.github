Radii is supply chain as a service for CNC manufacturing in Mexico. Aerospace and automotive teams send us a CAD model or a 2D drawing, and get back a price, a vetted shop that can hold the tolerances, and the quality documentation the part has to travel with. Nearshoring, without the months of vendor hunting.

## What we build

**Instant quoting.** A price for a machined part in minutes instead of days, from a CAD model or a 2D drawing, with the cost broken out line by line.

**Reading the drawing.** Material, tolerances, finishes and dimensions pulled off a print automatically, along with the rules for which source wins when the drawing and the request disagree.

**Sourcing.** Matching each part to a shop that can actually make it, across a vetted network of machining partners in Mexico.

**Quality.** Inspection and documentation carried with the order instead of chased down after it.
